# AIGRA Ops

AI-powered Autonomous DevOps, SRE, Testing, and Defensive Security Operations platform.

## Getting Started

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

2. Start the platform with Docker Compose:
   ```bash
   docker-compose up --build
   ```

3. Access the dashboard:
   - Frontend: `http://localhost:3000`
   - Backend API Docs: `http://localhost:8000/docs`

## Phase 1 Features
- Project Management
- Website Monitoring
- Incident Detection
- Role-based Access Control (MVP)
